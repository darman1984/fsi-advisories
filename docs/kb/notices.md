## 3. 흐름

권고끼리 이어진 것은 [온톨로지](ontology.md) 2절의 "이어짐" 표에 권고 ID로 정리했어요.

- **같은 주제가 하루에 몰린 날**: 2026-10-22에는 [PHP](products/php.md) 권고가 세 번 왔어요. 보안조치 권고(`:950`), 보안 업데이트 권고(`:958`), 대응 수칙(`:966`) 순서예요. 하루 안에 주의 → 패치 → 수칙으로 이어진 것으로 보여요.
- **주의 뒤에 패치가 온 제품**: HiveOn과 SoftManager는 07-03에 주의 권고(`:424`, `:432`), 07-10에 다시 권고(`:467`, `:475`)가 왔어요. HiveOn은 두 번째가 "보안 업데이트 권고"예요.
- **자주 다시 오는 제품**: [Cisco](products/cisco.md)와 [Linux Kernel](products/linux-kernel.md)이 7번, [Citrix·NetScaler](products/citrix-netscaler.md), [Fortinet](products/fortinet.md), [MS 정기 업데이트](products/microsoft-patch.md)가 5번이에요. 이 제품을 쓰면 한 달에 한 번꼴로 권고가 온다고 보면 돼요.
- **Fortinet은 10월에 연달아 왔어요**: 10-22 저녁(`:982`)과 10-23 아침(`:991`)에 하루도 안 돼서 두 번 왔어요.
- **MS 정기 업데이트**: 6월부터 9월까지 한 달에 한 번 왔어요(06-11 `:237`, 07-16, 08-19 `:648`, 09-09 `:759`). 날짜는 달마다 달라서 날을 정해 두고 기다리기는 어려워요. 10월 권고는 2026-10-23까지 오지 않았어요. 7월에는 같은 날 13:19(`:493`)와 22:14(`:501`)에 같은 제목으로 두 번 왔어요. 고쳐서 다시 올린 것인지는 알림만으로 알 수 없어요.
- **CVE 번호가 제목에 있는 권고는 두 건뿐이에요**: Oracle WebLogic CVE-2026-21962(`:716`), NetScaler CVE-2026-88771~88778(`:820`). 나머지는 원문에서 CVE를 확인해요.
- **오는 시각**: 117건 중 91건이 오후 5시 이후에 왔고, 밤 11시 넘어서 온 것도 있어요(예: 09-29 23:58 `:837`). 업무 시간 외 알림을 끄면 다음 날 아침에 몰아서 확인해야 해요.
